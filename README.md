# 약속 · 어르신 약 복용 알림 (React 퍼블리싱)

디자인 시안 4개 화면(홈 · 복용 알림 · 약 시간 설정 · 복용 기록)을 React로 옮긴 프로젝트입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 폴더에 배포용 파일 생성
```

Node.js 18 이상이 필요합니다.

## 동작하는 것

- **홈**: "먹었어요"를 누르면 오늘 현황 동그라미와 일정 목록이 바로 바뀌고, 다음 약으로 넘어갑니다.
- **알림 미리보기**: 홈 아래 버튼으로 알림 화면을 볼 수 있습니다. "먹었어요" / "10분 뒤에 다시" 동작.
- **시간 설정**: −/+ 버튼으로 10분씩 조절, 시간대별 알림 켜기/끄기, "저장하기"를 눌러야 반영됩니다.
- **기록**: 오늘 드신 횟수가 주간 합계에 더해집니다. "가족에게 보내기"는 안내 메시지만 띄웁니다.

## 폴더 구조

```
src/
  App.jsx            화면 전환과 공통 상태(약 시간, 복용 여부, 안내 메시지)
  data.js            예시 데이터와 설정값(10분 단위, 보호자 알림 30분 등)
  time.js            "오전 7:30" 같은 시간 표기 함수
  styles.css         색상·글자 크기 토큰과 전체 스타일
  components/        Icon(선 아이콘), TabBar(하단 메뉴)
  pages/             Home, Alarm, Schedule, History
```

## 실제 서비스로 갈 때 바꿀 곳

- `App.jsx`의 `NOW_MINUTES`는 시안과 같은 화면을 위해 낮 12:00으로 고정돼 있습니다. `new Date()` 기준으로 바꾸세요.
- `data.js`의 약 이름·기록은 예시입니다. 서버나 기기 저장소에서 불러오도록 바꾸세요.
- 실제 알림(푸시), 보호자 연락, 기록 전송은 아직 연결돼 있지 않습니다.
- 화면 전환은 의존성을 줄이려고 `useState`로 했습니다. 주소(URL)가 필요하면 react-router를 붙이면 됩니다.

## 접근성

- 본문 글자 20px 이상, 버튼 높이 56px 이상
- 모든 버튼은 실제 `<button>`이라 키보드·스크린리더로 조작 가능
- 색만으로 구분하지 않도록 체크(✓)/느낌표(!) 모양을 함께 사용
